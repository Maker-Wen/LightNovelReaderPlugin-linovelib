## 维护约定

- 用户可见行为和安装限制放在根 README；构建、测试命令集中在开发文档。
- 改动模块职责或状态归属时更新架构文档；改动迁入行为时更新迁入规则。
- 一次性设计、审查和验收使用 `archive/YYYY-MM-DD-topic.md`，记录代码或包基线及未覆盖项。
- 使用相对链接引用仓库文件；本机日志、截图、临时脚本路径以代码文本保留，并说明其时效。
- 测试通过、设备验证、签名覆盖升级和发行状态分别记录，避免互相替代。
