# Linovelib 2.2.0

## 更新内容

- 新增上游 Linovelib TW 本地数据的一次性迁入，合并书架、阅读位置、阅读统计及可用缓存，继续使用一个 Linovelib 数据源。
- 改善历史数据兼容：尽量迁入可恢复的字段和缓存，保留当前源已有的个人记录；没有可恢复内容或完成凭据不可信时跳过迁入，不阻止正常阅读。
- 修复不同展开页之间的分页和筛选状态相互影响，切换筛选后重新从第一页加载。
- 统一列表、搜索和详情的信息识别与映射；详情补全失败时保留已找到的书籍和已有信息。
- 改善网络会话、Cookie 与取消处理，首页临时缓存只记录实际展示的摘要。

## 升级与迁入

适用于 LightNovelReader API 3，Android 7 及以上。包名和数据源 ID 保持不变；从本项目旧版直接导入同签名的新包，无需先卸载。

使用阅读器打开 `Linovelib-2.2.0.apk.lnrp` 完成安装；若插件开关被宿主关闭，请在“扩展插件”中重新启用 Linovelib，再彻底关闭并重新打开阅读器。

检测到可迁入的 TW 数据时，普通冷启动会显示“合并 TW 数据”。确认后等待完成，再按提示重新打开阅读器。迁入只执行一次，不做增量同步，也不重复累计已迁入的统计。

## 已知限制

部分官方 API 3 宿主仍存在主题筛选弹窗无法完整滚动、作者与标签点击回调不匹配、连续滚动切章及离线无缓存详情反馈不足等问题，本版未修复这些宿主行为。

迁入期间外部安装窗口仍可能覆盖进度。同包覆盖安装会结束当前迁入；已测路径会安全回滚，重新启用插件并重开阅读器后可再次确认迁入。该行为不等同于外部入口已被屏蔽。
